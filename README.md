# 俄留マップ

久世祭り・宵祭りのお花回りで、俄留（にわかどめ）を貼った家・不在の家・断られた家・未訪問の家を、チームで地図上に共有するWebアプリ。

- 地図：国土地理院（標準／航空写真／淡色）（右下の「地」ボタンで切り替え）
- 共有：Firebase（Firestore）でリアルタイム同期。電波が悪くても端末に一時保存され、つながったら自動で送信される
- 料金：Firebase の無料プラン（Spark）の範囲で十分まかなえる

## フォルダ構成

```
niwakadome-map/
├─ firebase.json        … Firebase Hosting / Firestore の設定
├─ firestore.rules      … データベースのアクセスルール
└─ public/              … 公開されるファイル
   ├─ index.html
   ├─ style.css
   ├─ app.js
   └─ firebase-config.js … ★ここに自分の Firebase の設定を貼る
```

## まず手元で試す（お試しモード）

`firebase-config.js` が空のままだと、データをその端末のブラウザだけに保存する「お試しモード」で動く。

`public/index.html` をダブルクリックしてブラウザで開くだけで試せる（インターネット接続は必要）。
※ ファイルを直接開いた場合、「今いる場所」の機能はブラウザによって使えないことがある。公開後の https のURLなら使える。

## 公開する手順（30分くらい）

### 1. Firebase プロジェクトを作る
1. https://console.firebase.google.com/ で「プロジェクトを作成」（名前は例：`niwakadome-kuse`。Googleアナリティクスはオフで良い）
2. 左メニュー「構築 → Authentication」→「始める」→ ログイン方法で **匿名** と **Google** を有効にする（Google は管理者のログイン用）
3. 「構築 → Firestore Database」→「データベースを作成」→ ロケーションは `asia-northeast1`（東京）、本番環境モードで作成
4. 「プロジェクトの設定（歯車）→ 全般 → マイアプリ」で **ウェブアプリ（`</>`）** を追加（Hosting のチェックは任意）
5. 表示された `firebaseConfig` の値を `public/firebase-config.js` に貼り付ける

> `apiKey` などは公開しても問題ない値（アクセス制限は firestore.rules で行う）。

### 1.5 管理者を決める
管理者の Google アカウントのメールアドレスは、**Firebase コンソールのルールにだけ** 書く（公開リポジトリや公開ファイルには書かない）。
1. Firebase コンソール →「Firestore Database」→「ルール」を開く
2. `function admins()` の中にアドレスを小文字で並べて「公開」を押す
```
function admins() {
  return [
    'shinkun@gmail.com',
    'kaicho@example.co.jp'
  ];
}
```
- Gmail 以外のアドレスでも、そのアドレスで作った Google アカウントなら使える
- アプリは「管理者だけが読める場所（adminProbe）」を読めるかどうかで管理者かを判定するので、アプリ側の変更はいらない
- リポジトリの `firestore.rules` はアドレスを伏せた見本。ルールを直したら、アドレス以外の部分はこのファイルにもそろえておく

### 2. Firebase CLI で公開する
Node.js が入っていれば：
```
npm install -g firebase-tools
firebase login
cd niwakadome-map
firebase use --add            # さっき作ったプロジェクトを選ぶ
firebase deploy               # Hosting と Firestore ルールを両方反映
```
終わると `https://<プロジェクトID>.web.app` が表示される。それがアプリのURL。

### 2.5 ルールが効いているか確認する（おすすめ）
Firebase コンソールの「Firestore Database → ルール → ルールのプレイグラウンド」で試せる。
- 匿名ユーザーで `teams/<合言葉>` に書き込み → **拒否** されればOK（年度は管理者しか変えられない）
- 匿名ユーザーで `teams/<合言葉>/houses/<id>` の `hidden` を `true` → `false` に更新 → **拒否** されればOK（元に戻すのは管理者だけ）
- 管理者のメールアドレスで認証した状態で同じ操作 → **許可** されればOK

### 3. チームで使う
1. 自分がURLを開き、名前を入れて「新しいチームを作る」
2. 右上の「招待」でリンク（`…?team=xxxxxxxxxxxx`）をコピーし、チームのLINEに送る
3. みんなはリンクを開いて名前を入れるだけ。スマホの「ホーム画面に追加」をしておくとアプリのように開ける

## 使い方
- **家を追加**：「＋ 家を追加」→ 地図の家をタップ。玄関前にいるなら「今いる場所に追加」が早い
- **状態を変える**：ピンをタップ → 6つの状態から選ぶ
  - 未訪問（可）／未訪問（不可）／お花受取済／俄留を貼った／不在・再訪／断られた
  - 夜9時前に「俄留を貼った」を押すと確認が出る（お花だけもらったなら「お花受取済」）
  - お花受取済の家があると上にピンクの帯が出る。9時を過ぎると「俄留を貼る時間です」に変わり、タップするとその家の一覧が出る
- **メモは2種類**：「家のメモ」は毎年使う情報（裏口から、など）。「今年のメモ」はその年だけの情報
- **過去の記録**：ピンを開いて「過去の記録」で、年ごとの結果とメモが見られる。左上の年度を選ぶと、過去の年の地図全体も見られる（見るだけ）
- **家を消したいとき**：「この家を非表示」。記録は残っていて、管理者が「管理」から元に戻せる
- **位置がずれた**：ピンを開いて「位置を直す」→ 正しい場所をタップ
- **残りを確認**：上の色つきチップで件数と絞り込み、「一覧」タブは未訪問が上に並ぶ
- **メンバーの現在地**：右下の人のマークを押すと、自分の位置がチームの地図に紫の点で表示される（自分は青）。もう一度押すと共有をやめる。マークの数字は、今共有している自分以外の人数
  - 共有されるのは、自分でオンにした人だけ
  - 送信は60秒に1回まで。立ち止まっているときは5分に1回だけ。画面を消す・別のアプリに切り替える・アプリを閉じるとすぐ消え、戻ると自動で再開する。消し損ねた場合も7分更新がなければ表示されなくなる
  - 無料枠（1日 読み込み5万回）の目安：10人が3時間共有しても約1.8万回。共有する人を班のリーダーだけにすると、さらに少なくなる
  - スマホのブラウザは、画面を消したりほかのアプリに切り替えたりすると位置を送れない（アプリを開いている間だけ）
  - 位置情報を使えるのは https で公開したURLだけ。ファイルを直接開いた場合は使えないことがある
- 右上の表示が「未送信あり・電波待ち」なら、まだサーバーに届いていない（電波が戻れば自動で送られる）

## セキュリティについて
- 合言葉（12文字のランダムな英数字）を知っている人だけがそのチームのデータを読み書きできる。リンクはチームの中だけで共有すること
- 家の名前とメモ程度を想定。金額などの細かい情報を残すかはチームで相談して決める
- 祭りが終わったら、Firebase コンソールの Firestore から `teams` のデータを削除・エクスポートできる

## 管理者の操作（右上の歯車 →「管理者としてログイン（Google）」）
- **年度の切り替え**：祭りの前に「2027年を始める」。家のリストと家のメモはそのまま、全部の家が「未訪問（可）」から始まる。前の年が「未訪問（不可）」または「断られた」だった家は「未訪問（不可）」になる。前の年の記録は消えない。間違えたら「〇〇年に戻す」
- **非表示にした家を元に戻す／完全に削除する**（削除は確認が出る。過去の記録も消えて元に戻せない）
- **メンバーも家を非表示にできる**：オンなら誰でも非表示にできる（最初の2〜3年向け）。情報がたまったらオフにして、メンバーは追加だけにする
- 年度が一度も設定されていないチームは、今日の日付から自動で年度を決める（1〜3月は前の年として扱う）

## データの形（Firestore）
```
teams/{合言葉}                … year（今の年度）, allowHide（メンバーが非表示にできるか）
teams/{合言葉}/houses/{id}    … name, lat, lng, memo（家のメモ）, hidden,
                                 years: { "2026": { status, note, updatedAt, updatedBy }, "2027": {...} }
teams/{合言葉}/members/{uid}  … 位置を共有中のメンバー
```
